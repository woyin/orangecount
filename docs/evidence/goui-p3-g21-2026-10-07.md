# G21 账户详情初版证据

日期：2026-10-07。本记录证明账户详情与回报表的自动化初版，不表示 G21/P3 完成。

## 实现

- 资产负债表/损益表账户行提供明确“查看账户”动作，打开独立账户详情页，并记录返回页面、原报表响应和快照。
- 详情读取核心 account projection，显示账户 direct/subtree 数额、期间变化、explicit/目录状态、opened/closed、booking、生命周期 source、按币种历史和exact表格。
- 估值完整度与缺项原因映射为用户文案；账户详情真实 Session 测试覆盖外币余额缺少本地报价时的状态和商品原因，不再呈现核心枚举码。
- 账户详情 payload 携带 source file ID 到路径的映射；页面显示实际采用的市场报价日期、精确汇率、报价方向和来源位置，并提供 Finder 与源文件动作。
- 账户关联流水默认选中首笔交易；交易级 metadata/source 与分录级 metadata/source 在详情中可读，并可用 Finder 定位来源。
- 账户页复用核心账户流水，带日期/范围、搜索和最多100条分页；可检查交易分录单位、cost和price。账户本身/含子账户切换同时作用于核心摘要与流水。
- 返回时只有当前 Session 仍为同一快照才重用先前报表响应；筛选状态由原窗口 Model 保留。
- 账户树使用 MyGo `OutlineState.List.Selected`，并在相同快照返回时按稳定账户全路径恢复选择；新快照会清空旧选择。
