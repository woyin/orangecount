# G12 账本诊断语言偏好

日期：2026-10-07。工作区基线 `1c2096d`，工作区有未提交改动；本次仅在既有 Go UI 改动上增加诊断语言偏好。环境：macOS 27.0.1 arm64，Go 1.27.1。

## 实现

- 每账本偏好增加 `locale`，只接受核心已支持的 `zh-CN` 和 `en`；未填写的旧偏好继续按简体中文处理。
- 打开账本后，侧栏可切换“诊断语言”；该选择仅影响核心生成的诊断文本，不改变当前页面和筛选，也不会被筛选偏好的后台写入覆盖。
- 全部 Go UI 页面请求（仪表盘、报表、账户、流水、商品/价格、持仓、指令、附件、语义比较和查询目录）携带该账本的诊断语言。切换时重读当前投影；本地附件目录页等页面保留原位置。
- 全页面 en/zh-CN 界面资源尚未实现，仍属于 G36；本功能不代表整个 UI 已完成本地化。

## 验证

以下命令在上述环境通过：

- `cd apps/goui && GOWORK=off go test -race -count=1 ./...`
- `cd apps/goui && GOWORK=off CGO_ENABLED=0 go vet ./...`
- `make goui-check`
- `make license`
- `git diff --check`

应用 headless 测试实际打开语言菜单并选择 English，验证重启读取后的偏好、请求语言覆盖所有页面，以及只更新 locale、不覆盖已保存日期/币种。账本打开集成测试确认恢复的 English 在首次核心读取前生效。当前未进行真实 macOS GUI、VoiceOver 或系统语言验收。
