# G15 表格与账户树初版证据

日期：2026-10-07。此记录证明账户报表接入原生 OutlineTable 的初版和 headless 测试，不表示 G15 或 P2 已完成。

## 实现

- 资产负债表和损益表用 MyGo `OutlineTable` 展示核心生成的账户树，支持逐行展开/折叠、全部展开和全部折叠。
- 每行以账户完整名称作为稳定 key 与辅助功能 label；币种列保持独立，金额直接使用核心 exact projection 的展示值。
- 每个输入快照首次显示时展开账户层级，后续折叠状态由 OutlineState 保留；输入 snapshot 改变时初始化新树。

## 验证

- `TestStatementPageRendersExactAccountTreeFromCore` 使用公开 `cashflow.bean` 和真实 desktop Session，核对树内容、金额、行身份/标签及全树展开折叠。
- `make goui-check` 的 headless Go UI suite 和 CGO-disabled app build 通过。
- 该记录不包含真实 macOS 键盘导航、VoiceOver、列重排/宽度保存、typed 排序或 exact copy 验收。

## 未完成

G15 还需通用表格/金额/来源控件、typed 值比较、重排筛选后的选择稳定性、动态多币种缺值和精确复制测试。G16 还需账户搜索、返回导航、报表导出联动以及更多公开 fixture 和实机页面验收。
