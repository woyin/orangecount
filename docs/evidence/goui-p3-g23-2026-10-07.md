# G23 商品与价格初版证据

日期：2026-10-07。本记录证明商品目录/价格历史页面和自动化初版，不表示 G23、P3 或迁移完成。

## 实现

- 新增原生“商品与价格”导航页，切换商品目录和报价历史；请求固定当前快照，携带日期、排序和分页，目录请求不携带历史 pair 参数。
- 商品目录列出商品、使用账户、报价币种、历史价格数和声明数；搜索在完整核心目录分页前过滤商品/账户/报价币种，清除后保留当前商品选择。选择商品后展示账户、可用 pair、逐条声明来源及 Finder 操作。报价历史使用目录选定的 base 和可换选的 quote，展示截止日 direct/inverse 报价、exact 曲线与表格、来源位置、行选择和 Finder 操作，并支持独立分页及正/倒序。
- Chart exact 表格与价格来源表使用独立 MyGo ListState，避免同一列表状态被两个列表控件共享。
- 核心价格记录的 source segment 传入可复用 chart point；分段布局和绘图抽样都会在显式 segment 边界断开。
- 2026-10-08 价格历史 exact 表新增“来源段”列，以 1 起始显示每条来源记录所属的连续绘图段；不可绘制报价后的断线位置现在也能从表格读取。
