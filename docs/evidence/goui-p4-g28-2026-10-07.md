# G28 查询目录与显式预设保存证据

日期：2026-10-07。本记录覆盖查询目录和用户命名预设的自动化闭环，不表示 G28 或 P4 完成；真实 macOS 键盘/VoiceOver验收尚未完成。

## 实现

- 查询页显示核心 `QueryCatalogue` 中的四个内置 BQL 模板及当前账本保存查询，显示日期、source path/line 和分页。
- 选择只替换可编辑草稿并提示“尚未执行”；运行仍需单独点击“执行查询”或 Cmd+Enter。
- 目录请求绑定当前 snapshot，不继承其它报表的共享日期/币种筛选；目录响应与当前 snapshot 不同则隐藏选择入口。
- 目录在分页前按日期、名称过滤；排序可切换日期升序/降序；搜索范围覆盖日期、查询名及BQL文本。
- 独立日期范围可调用核心期间模板生成逻辑；快照或日期输入变化后，旧生成结果不可选。
- 用户明确保存的命名预设保存在独立 `query-presets-v1.json`，以账本身份哈希隔离；支持重开读取、确认后删除、名称唯一性与文本/数量/文件大小限制。写入使用原子替换及0600/0700权限，不记录账本原路径。
- 用户自定义预设选择仍只填入草稿；没有预设或目录操作会自动执行查询。普通草稿、结果和附件不写入自定义预设文件。
- 查询页面使用独立虚拟 ListState，与查询结果 Table 状态分开。

- `GOWORK=off go test ./internal/querypresets ./internal/app -count=1`（`apps/goui`）通过。
- `TestQueryCatalogueSelectionOnlyFillsTheDraft` 和 `TestSavedUserPresetSelectionOnlyFillsTheDraft` 使用真实 `queries.bean` Session/Headless UI，检查内置模板、账本查询、期间模板和用户自定义模板选择都不产生 QueryResponse。
- `querypresets` store测试覆盖重开、账本隔离、删除、重复名称、无效/过长BQL拒绝、未知schema保护、并发写入和文件权限。
- 当前改动后的 `make goui-check`、UI module `GOWORK=off go test -race -count=1 ./...`、`GOWORK=off CGO_ENABLED=0 go vet ./...`、根 `GOWORK=off go test -count=1 ./...`、`GOWORK=off go test -race -count=1 ./internal/desktop`、`make license` 和 `git diff --check` 均通过。
