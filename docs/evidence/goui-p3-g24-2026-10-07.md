# G24 原生图表交互初版证据

日期：2026-10-07。本记录证明基础线图/分组柱、精确表格和悬停值初版，不表示 G24、G20 或 P3 完成。

## 实现

- `internal/charts` 提供 MyGo Painter 线图、分组柱和相邻 exact `ui.Table`。近似 float 只进入几何，财务显示继续使用来自核心 projection 的 exact 文本。
- 折线和柱图支持按指针横坐标选择最近期间、绘制期间指示线，并通过 MyGo Tooltip 显示 exact 数值；分组柱提示显示各 series 的 exact 金额与缺失原因。
- 分组柱顶部提供颜色标记与系列名称图例，避免只依赖悬停或下方表格识别收入/支出。
- 分组期间是所有 series 的排序并集，series 顺序稀疏时按日期定位，不按数组位置错配。缺失值断开折线且不绘柱，已知零值保留并有单独的 zero mark，负值进入范围计算。
- 图表可 Tab 聚焦；左右键切换原始期间，Home/End跳至首尾。提示与辅助技术描述包含当前期间 exact 文本，详见 G07 记录。
- Painter 路径按图表宽度分配采样预算；折线按连续有效段分别抽样，每桶保留首尾和局部最小/最大，缺价断点不会被跨越。为了不丢断点，极端高缺失密度下折线样本可能超过预算。分组柱按排序期间并集采样，每桶保留边界及每个 series 的局部极值；密集柱宽至少为0.5 DIP，允许重叠以保留范围线索。
- 折线段还尊重核心投影显式携带的 source segment；即使两边数值均可绘制，也不会跨 source segment 连接。
- 抽样只影响绘图几何。指针/键盘索引仍对完整原始 series 定位；exact table 和提示读取未抽样值。
- 2026-10-08 将实现拆为 `model.go`、`layout.go`、`hit.go`、`render.go` 和 `table.go`。包内纯布局结果由 Painter 绘制器直接消费；对外仍只暴露 `Line`、`GroupedBars`、`ExactTable`，调用方不接触 Painter 几何与抽样细节。
- 布局每次根据 MyGo 当前 viewport 计算，主题颜色每次从当前 Theme 传给绘制器；暂不缓存布局，避免窗口尺寸/scale 与主题状态的陈旧缓存。若基准证明重算成本需要优化，再增加有明确数据版本和 viewport key 的私有缓存。
