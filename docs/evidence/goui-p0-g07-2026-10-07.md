# G07 图表键盘选择与精确值记录

日期：2026-10-07

## 本轮完成

`apps/goui/internal/charts` 的折线图和分组柱状图现在可通过 Tab 获得键盘焦点，左右箭头逐期选择，Home/End跳至首尾。当前期间精确文本显示在聚焦提示中，并同步放入图表的辅助技术描述；鼠标移动仍可直接选择期间。鼠标离开时保留聚焦中的键盘选择，失焦后清除键盘选择或恢复当前悬停点。

headless 用例 `TestLineKeyboardSelectsExactPeriod` 和 `TestGroupedBarsKeyboardSelectsExactAndMissingPeriod` 验证键盘选择与精确提示，包括负值、可用零值、缺失值。既有悬停精确值、缺值断线、精确表格，以及1×/2×绘图测试也覆盖在同一个 charts package 中。

## 2026-10-08 原生鼠标命中补充

新增原生鼠标验收时发现生产命中计算把 `Element.PointerPosition()` 的局部坐标与 `Element.Bounds()` 的窗口坐标混用；图表位于侧栏右侧时，点击中间期间会错误选择首期。现已将命中区域改为图表局部坐标，并增加偏移布局下的折线图和分组柱状图 headless 回归。

macOS 原生窗口测试现在使用 AppKit 点击三个月现金流分组柱状图的中间位置，再从 Accessibility help 核对二月收入 `1500 USD` 和支出 `300 USD`。新增原生鼠标动作后的图表场景连续5次通过；完整原生窗口套件和常规 UI 检查见任务台账。

尚未验收真人 VoiceOver 朗读以及真实显示器缩放和深浅主题下的图表外观与可读性。自动读取 Accessibility help 不等同于 VoiceOver 朗读，故 G07 仍进行中。

## 2026-10-08 补充：折线图原生命中与主题回归

原生现金流窗口场景现同时检查折线图和分组柱状图：键盘聚焦后按 Home/Right 选择对应月份，AppKit 鼠标点击中点后核对精确值 help。最新场景还切换英文并核对图表辅助功能名称、键盘说明和 exact-value 表格的 `Period` 表头。完整 `make goui-native-e2e` 通过，新增组合场景 `-count=5` 连续5次通过。

`TestLineBarsAndExactTableRenderAtOneAndTwoScale` 现于 1×、2×分别先渲染浅色，再切换深色，检查图像发生重绘且 exact 表格值仍可读；定向测试及 `make goui-check` 通过。缺失净资产点 exact 状态的中英文显示也有独立 Headless 回归。临时 development 包打开公开 `cashflow.bean` 后，实际 Accessibility 树显示英文折线图/柱状图名称、键盘帮助和 `Period` 表头。

这些自动化检查不能证明 VoiceOver 实际朗读质量，也不能替代真实显示器缩放与系统外观下的视觉检查；两项仍未验收，G07 继续进行中。
