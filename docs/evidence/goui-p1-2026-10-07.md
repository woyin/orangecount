## 实现事实

- `apps/goui/internal/workspace/controller.go` 将每窗口的 Engine/Session、工作区 epoch、操作序号、状态 revision 和关闭清理集中管理。异步 Open 失败会保留旧工作区；晚到结果会被丢弃，晚到创建的 Session 会关闭。
- 读取队列最多保留一个执行中任务和一个最新等待任务；新的请求替换旧的等待请求。epoch、operation 和 session generation 不匹配的结果不会发布。ledger 正在重载时，新读取返回 `ErrBusy`，避免把上一次 build 的诊断投影为当前输入结果。session Close 会等待已启动的后台工作释放资源。
- 读取请求会补齐 core 默认 View/Locale/account scope，并绑定 Dispatch 时的 SnapshotID；发布前校验完整 Request、workspace epoch/operation、session generation、snapshot identity 和 ledger revision。旧 revision 被当作 stale，read error 保留上次成功 projection。
- 查询 runner 与报表读取队列分离；每窗口 request ID 单调递增，查询直接接收 context 并经 `CancelQuery` 快速取消。账本切换、reload、快照变化和关窗会使旧查询失效，迟到执行不能发布。
- 报表捕获独立分配有界 `CaptureID`，`CancelReportExport` 直接调用当前 Session，不排在捕获 goroutine 后。捕获状态在账本切换、reload、快照变化和关窗时失效；成功字节和保护路径会复制到发布状态。
- 每个 MyGo 窗口有不同 `windowID` 和独立 Controller；`WindowOptions.Content` 使用原生 `ui.View`，不设置 Page/WebView。Finder 文档事件会落到空窗口或新窗口，不覆盖已有/忙碌工作区；欢迎页展示最多五项最近账本，必须由用户显式打开，不会在启动时自动读账。
- 新增版本化 `preferences-v1.json` 用户偏好 store，QA 与开发身份通过 MyGo `PathUserData` 隔离。每账本设置用规范化路径的 SHA-256 identity 索引；为支持最近账本，只有独立最近列表保存绝对路径，受 `0600` 文件与 `0700` 目录保护。profile、期间、日期、币种、估值和预留列顺序使用串行 read-modify-write、fsync 与原子 rename；坏 schema 不会被静默覆盖。
- 旧 `org.orangecount.desktop` defaults reader 已用 purego Objective-C Runtime 只读获取明确 allowlist：最近路径、每账本 semantics、currency、valuation 和旧 Codable 附件 roots NSData；一次性 marker 写在新 JSON 中，旧 defaults 保持不变。QA 不读取旧 defaults。注入式测试验证单次迁移、从上一迁移版本升级、未知字段忽略、不覆盖已有 Go 偏好与 missing recent path 保留；Darwin 运行时测试在临时 suite 中验证 Foundation reader 可读 NSArray/NSString/NSDictionary/NSData，且读取不改源值。新账本默认 profile 修正为旧客户端的 `legacy`。Darwin ordinary NSURL bookmark adapter 已实现并在临时目录通过往返、移动/替换、删除与损坏数据测试；它使用 withoutUI/withoutMounting，不请求 security scope。roots bookmarks/generation 已进入版本化 JSON 偏好，并驱动目录管理 UI、启动恢复、Session policy 与同进程窗口通知。真实旧生产 defaults 域和旧 bookmark 数据读取仍待验。
- 打开账本时先恢复该账本的 profile/reading controls，成功发布新工作区后才替换当前窗口控件；第一次页面读取使用恢复值。应用筛选后异步保存，失败显示偏好保存诊断，不阻塞账本读取；关窗等待已启动的偏好写入完成。
- UI 目前实现欢迎/首页、核心投影驱动的仪表盘、资产负债表、损益表、最多100笔交易流水和选中交易分录详情；查询工作台初版已进入实现，详见[P4 证据](goui-p4-2026-10-07.md)。全部指令/配置阅读初版及 fixture 证据见[P2记录](goui-p2-2026-10-07.md)。附件页筛选核心 document DTO，展示状态并通过 Session ID/snapshot/policy 重验证后打开或显示；roots 页管理普通 bookmark，按同进程通知同步撤销。还保留 QA 专用虚拟表格/图表验证页。页面读取只使用 `internal/desktop` 的公开 ViewResponse。
- 首页按核心返回的币种系列分别展示净资产与现金流；图表精确值通过相邻 Table 保留，缺值标为 `Unavailable`。账户报表读取核心账户树，按币种显示精确金额，并保留近似提示。
- 图表精确表格按所有 series 的日期并集对齐稀疏时间序列，避免某条序列缺月时金额落到错误月份。
- 报表壳现在提供起止日期、原币/目标币种和按成本/按市价选择；日期输入严格校验 `YYYY-MM-DD` 和起止顺序，只有按下“应用筛选”后才提交请求。控制项的值进入核心 `desktop.Request`，不会只改变界面标签。
- 报表壳增加“近1月/近1年/全部”预设；预设会清除自定义日期并把标准 `Window` 发送到核心。打开账本和应用筛选时的 per-ledger 设置已接入偏好 store。
- 诊断列表显示级别、代码、消息和源文件行列；安全动作目前为“在 Finder 中显示来源”，避免通过默认 `.bean` 文件关联重新启动 OrangeCount。完整外部编辑器打开与错误选区仍未实现。

## macOS QA 观察

- 在真实 QA 窗口用原生打开面板打开公开 `cashflow.bean`，页面显示3个账户、2笔交易、5条分录；首页显示USD净资产700、收入1000、费用300。
- 打开资产负债表、损益表与流水页；页面可见 Bank 700、收入/费用金额，并从 Salary 交易选择到账户与精确分录金额。
- 新建第二个窗口并打开公开 `empty.bean`，其页面显示1个账户、0笔交易、1条分录。切回首窗口后仍保留第一份账本数据与已选交易；关窗时另一工作区可继续使用。
- 文件监听试验先载入临时账本的50 USD状态，再写入语法错误：UI 显示上次有效快照和最新诊断，仍保留50 USD；修复并追加交易后，UI 自动恢复有效状态，显示新快照与75 USD。
- 筛选 UI 实机检查再次使用公开 `cashflow.bean`：无效日期显示格式错误且没有提交；选择 `2026-01-01` 至 `2026-01-31`、USD 与市价估值后，页面标题更新为 `USD · market-value`，核心返回保留相应时间区间和金额表。
- 本轮最新 QA build 通过 Finder `open -a` 载入仅含合成 document 指令的临时账本，真实窗口显示正确账本摘要。之后 macOS Assistive Access 拒绝本轮 `System Events` 按钮点击（`osascript is not allowed assistive access`, `-1719`），所以附件页的 Finder/默认应用点击没有记为实机通过；QA 进程已退出，临时账本与附件已删除。
