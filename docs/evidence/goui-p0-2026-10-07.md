## 本轮执行与观察

- `apps/goui` 是独立 module `orangecount/apps/goui`，Go 1.27.1；只在此 module 固定 MyGo 依赖，并以 `replace orangecount => ../..` 导入核心。根 `go.mod`、根 `go.sum` 未加运行依赖，根目录没有 `go.work`。
- `make goui-check` 通过：Go UI QA app 与测试以 CGO disabled 构建；`go test ./...` 覆盖 MyGo `ui.NewTester`、核心公开 fixture、图表及编辑器 offset。`GOWORK=off CGO_ENABLED=0 go vet ./...` 通过；`make license` 通过并仍报告核心无运行期 Go 依赖；`git diff --check` 通过。
- 独立 QA bundle ID 为 `org.orangecount.goui.qa`，应用数据名为 `OrangeCount Go UI QA`；开发身份另名 `OrangeCount Go UI Development`。QA 第一次实际启动在欢迎页，没有自动打开最近账本。窗口通过 `WindowOptions.Content: ui.View(...)` 创建；MyGo 对 Content 窗口不创建 Page。本轮没有使用 WebView、页面 URL、HTTP 服务或前端绑定。
- 实际 macOS QA 窗口：原生打开面板作为当前窗口的 sheet 显示；Escape 取消后回到欢迎页。之后只选择公开 `testdata/fixtures/native/cashflow.bean`，实际页面显示 3 个账户、2 笔交易、5 条分录。Cmd+Q 退出了 QA app。
- 实际窗口的 50,000 行合成虚拟表格只显示当前视口；图表试验页画出正负数折线、收入/支出分组柱，并通过标准 `ui.Table` 展示精确金额。滚动后四行数据可见，真实零值显示 `0.00 USD`，缺失显示 `Unavailable`。Headless 测试也在 1×/2× scale 构建图表并验证精确表格内容。
- `apps/goui/build/OrangeCount Go UI QA.app/Contents/MacOS/orangecount-goui` 是 `arm64` Mach-O。`otool -L` 只列出 libSystem、libresolv、CoreFoundation 与 Security；没有 WebKit、Swift 或 Go C archive 运行库链接。该观察不替代其他 macOS 版本测试。
- 查询编辑器审计确认固定 MyGo 修订未公开设置选区/插入点及滚动到诊断范围的 API。已加入 UTF-8 byte-range 到 rune-range 转换与中文、emoji、组合字符、CRLF、尾部和无效范围测试；未访问 MyGo 私有 editor，也未声称查询错误导航完成。所需上游/本地 patch 记录在 `apps/goui/patches/mygo-selection-api.md`。
- 后续 G04 实现了本地 fork：`apps/goui/third_party/mygo` 基于上述精确 commit，nested `go.mod` 将 MyGo 替换到该目录，且保留 `LICENSE` 与 `UPSTREAM.md`。新增 `ui.Element.SetTextSelection` 使用 Unicode rune offset，设选区、focus editor、显示 caret并触发TextArea reveal；marked IME composition期间返回false且不改selection。UTF-8→rune adapter 已接上公开 API。
- 当前验证：`GOWORK=off go test github.com/egoist/mygo/ui` 通过；`TestTextAreaSetTextSelectionPreservesUndoAndMarkedText`、`TestTextAreaSetTextSelectionRevealsTheCaret` 通过；`internal/widgets/queryeditor`用包含emoji的真实core式byte range选择并替换测试通过。以上是 headless/editor自动化证据，真实macOS查询页定位和真人输入法仍未验。

## 尚未取得的证据

这是原生窗口、账本打开和高成本技术验证的起点。编辑器公开选区 API 与自动化回归已经实现，查询编辑器/结果表初版已在[P4记录](goui-p4-2026-10-07.md)接入；真人输入法和实际 GUI 错误导航仍待验。最近账本与旧 defaults allowlist 迁移后来已实现，Foundation reader 通过临时 suite 运行测试，ordinary NSURL bookmark adapter 通过临时目录往返与身份校验，roots records 已接入版本化偏好迁移；真实旧 defaults 域和旧 bookmark 数据读取仍待验。双窗口/面板归属的完整矩阵、Finder/source editor 动作、工作区重载 GUI、VoiceOver、图表点命中、完整业务页面、长账本性能对比、macOS 13 实机和发行签名/公证仍未完成。开发预览与旧 SwiftUI 客户端目前并行存在。
