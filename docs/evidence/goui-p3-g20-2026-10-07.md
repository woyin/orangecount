# G20 仪表盘初版证据

日期：2026-10-07。本记录证明核心财务趋势投影的仪表盘展示初版，不表示 G20/P3 完成。

## 实现

- “财务概览”有独立页面和导航；欢迎页继续显示轻量摘要。
- 仪表盘消费核心 `HistoricalTrendsPayload`，按币种分别展示净资产折线、月度收入/支出分组柱、精确表格和区间合计。用于绘图的 float 不用于显示账务金额。
- MyGo 图表悬停初版通过原生 Tooltip 显示所选期间的 exact 值；准确值和不可用状态也保留在标准 Table 中。
- `native-multi`、`unavailable-currency`、`partial`、`unavailable-price`、`select-currency`、`empty` 等状态转换为中英文说明，避免把核心内部枚举直接呈现；未选择估值币种与空历史有不同提示。
- 新增真实 EUR 无本地报价账本：USD 净资产保留三个不可用月点，现金流只保留一月工资，二、三月不伪造零流量；页面明确提示本地报价缺失。
- 2026-10-08 趋势响应携带 quote FileID 到路径的来源映射。净资产图表 tooltip/辅助描述显示实际采用的直接或反向报价对、精确汇率、日期和 `path:line:column`；缺价点显示缺失商品与原因，来源来自核心 `AccountValuation`，UI 不重算报价。

## 验证

- 真实 `desktop.Session` headless 页面测试检查 cashflow fixture 的净资产变化、收入 1000 USD、支出 300 USD，以及 dedicated dashboard 页面身份。
- 真实 `desktop.Session` 多币种 fixture 测试检查 USD 与 EUR 分开显示，不把不同币种金额合计。
- `TestDashboardExplainsUnavailableChartAndCurrencyStates` 检查缺报价/部分可用图表状态和缺少估值币种提示。
- `TestDashboardShowsMissingQuoteAndOmitsQuietMonthFlows` 使用真实 `desktop.Session` 验证缺价点和静默月份行为。
- `TestDashboardChartTooltipShowsMissingReasonAndUsedQuoteSource` 通过真实 `desktop.Session` fixture 检查 quote 源文件映射，并悬停验证可用报价来源与缺价原因；图表层 `TestLineHoverKeepsQuoteDetailWithExactValue` 检查 exact 值与报价明细同时可读。
- `TestDashboardDateRangeBoundariesCarryBalancesAndFilterFlows` 覆盖单日闭区间、月末到显式月初的跨界、区间前余额结转、静默日无虚构现金流，以及反向区间被拒绝。
- 图表零值、缺值、负值、悬停 exact 值和稀疏月份见[G24图表记录](goui-p3-g24-2026-10-07.md)。
- 2026-10-08 新增 dashboard 报表导出上下文回归：原生币种 `native` 规范化为空币种，未指定估值规范化为 `at-cost`；同时检查 `ReportExportIdentity` 和捕获的分析文件 `NormalizedRequest`。测试先复现 identity/分析文件错误地保存 `native` 与空估值，修复后通过。
- 2026-10-08 报价来源、viewport 布局和日期边界更新后，`make goui-check`、根 `GOWORK=off go test ./...`/`go vet ./...`、Go UI app/workspace/charts race、Go UI `go vet ./...`、`make license` 与 `git diff --check` 均通过。
- dashboard 与账户/持仓导出上下文修复后，`go test ./internal/desktop -count=1`、`make goui-check` 与完整 `make goui-native-e2e` 均通过（原生 app 包测试 62.886 秒）。
