# G16 报表搜索初版证据

日期：2026-10-07。此记录证明账户报表搜索与父级精确汇总保护的初版实现，不表示 G16 或 P2 已完成。

## 实现

- 资产负债表和损益表增加账户名称/完整路径搜索、显式应用与清除。
- 搜索只裁剪 UI 可见的账户树行，保留命中账户的祖先；币种列仍从完整核心投影生成。
- 账户金额与父级汇总仍直接读取核心 `SubtreeAmounts`。搜索/折叠不在 UI 侧聚合或修改金额；未命中时显示空结果提示。
- 核心顶层分类金额固定显示在搜索树之外，因此无命中时仍能看到原报表汇总；折叠和搜索都不会改变汇总。
- 搜索输入限制为 4 KiB，超过限制会保留上次已应用筛选。
- 核心 `native-multi`、`unavailable-currency`、`priced`、`empty` 状态映射为中英文可读提示，UI 不直接暴露内部状态码。

## 验证

- `TestStatementSearchFiltersRowsWithoutChangingCoreTotals` 使用公开 `testdata/fixtures/native/cashflow.bean` 与真实 `desktop.Session`，检查大小写无关过滤、保留 `Assets` 祖先、隐藏无关账户、exact 父级金额保持不变、无命中时分类汇总继续显示和清除后还原行数。
- `TestStatementPageRendersExactAccountTreeFromCore` 继续验证可折叠树的稳定身份/标签、全部展开/折叠与精确投影。
- `TestStatementTreeExpansionResetsWhenReportContextChanges` 验证 balance/income 使用各自账户层级状态，切换报表时不会沿用不相关的折叠状态。
- `TestStatementPageExplainsNativeMissingQuoteAndEmptyStates` 使用公开 options/empty fixtures 检查缺 EUR→USD 报价提示、原币 USD/EUR 分列、截至日 2000-01-03 和空损益表状态。
- 当前源码验证：`make goui-check`、相关 Go UI race tests 和 `git diff --check`。
