# G42 Go UI 构建与开发包首轮记录

日期：2026-10-07。本记录证明生产构建约束、临时 unsigned development package 和独立 macOS workflow 已实现并完成本机打包检查；G42/P7及正式发行未完成。

## 实现

- `apps/goui/build.sh` 固定 `GOOS=darwin`、`CGO_ENABLED=0`、`-trimpath` 和空 Go build ID，允许显式选择 arm64/amd64架构。
- `apps/goui/package.sh` 生成带开发 bundle identity 的 `.app`、ZIP 和 SHA-256 文件；`Info.plist` 声明最低 macOS 13.0。打包时检查 Mach-O、Mach-O `LC_BUILD_VERSION minos` 与 plist minimum 相同。
- `Contents/Resources/build-info.json` 记录源码 revision/dirty状态、Go/MyGo版本、目标架构、最低系统版本及 unsigned/unnotarized状态。
- 包内包含 OrangeCount `LICENSE`/`NOTICE`、Go toolchain license/patents、resolved module graph 中各模块的完整 LICENSE 文本和生成版模块版本映射，以及 MyGo 完整上游 commit 与本地 patch 说明。字体与图标没有第三方文件依赖；包使用系统字体和原生/vector 绘制。
- `.github/workflows/goui.yml` 独立运行 macOS 15 核心冻结gate、Go UI build/test/race/vet、许可证检查和临时 unsigned package检查。`make goui-package` 提供本地入口；QA bundle identity 已与设计的 `org.orangecount.desktop.goui.qa` 对齐。

## 验证

- `make goui-check` 通过，并产出 arm64 Darwin build。
- `GOWORK=off go test -race -count=1 ./...` 和 `GOWORK=off CGO_ENABLED=0 go vet ./...`（`apps/goui`）通过。
- `make license` 和所有 Go UI shell 脚本的 `sh -n` 检查通过。
- `make goui-package` 使用临时输出目录成功；`plutil -lint` 通过，Mach-O 为 arm64，`otool -l` 显示 `LC_BUILD_VERSION minos 13.0`，bundle plist 的 `LSMinimumSystemVersion` 同为 `13.0`。
- 打包脚本通过 `go version -m` 确认 `CGO_ENABLED=0` 和 `GOOS=darwin`，检查 `otool -L` 不含 Swift runtime。
- ZIP 的 `.sha256` 使用 `shasum -a 256 -c` 验证通过；生成包内含每个 resolved module 的许可证文本及module/version对应清单。
- Ruby YAML parser 对 `.github/workflows/goui.yml` 解析通过。

```sh
cd build/goui-package-check-2-2026-10-08

```
