# G31 Go 安全文件保存 Module 验证

日期：2026-10-07。本记录覆盖 G31 的独立本地保存模块，不表示 G30、P5 或 MyGo 桌面迁移整体完成。

## 实现

- `apps/goui/internal/localfiles` 提供不可变 `Capture`：复制冻结字节，限制 16 MiB；只接受绝对保护路径；保留已有文件身份，并在 `WithProtectedPaths` 刷新时合并新路径但不丢失旧身份。读取内容和路径均返回副本。
- Darwin 保存流程规范化目标父目录并打开 `os.Root`；初始检查和提交前检查都验证父目录仍指向已打开的 filesystem identity。临时文件在同目录以随机名称、`O_EXCL|O_NOFOLLOW` 和 `0600` 创建。
- 保存使用完整写入循环（处理短写和 `EINTR`），随后 `fsync`、关闭、重查目标类型/保护身份/alias 与父目录，最后只经同一 `Root.Rename` 原子提交。出错、部分写入或提交前取消会删除临时文件并保留旧目标。
- `platform.IsFinderAlias` 使用 purego/Foundation 读取 `NSURLIsAliasFileKey`。测试通过真实 macOS NSURL bookmark-file API 创建 Finder alias，再确认保存流程拒绝覆盖；生产代码未加入 Swift 或 cgo。非 Darwin 构建保留明确的 unsupported 保存入口。

## 验证

- `TestSaveAtomicallyReplacesRegularFileWithFrozenBytes` 覆盖已有目标原子覆盖、新文件创建、输出内容和 `0600` 权限。
- `TestSaveRejectsProtectedPathHardlinkAndMovedSourceIdentity` 与 `TestProtectionRefreshRetainsMovedSourceIdentity` 覆盖源路径、硬链接，以及源移动并刷新保护路径后仍保留的 device/inode 身份。
- `TestSaveProtectsMissingSourcePathAndRejectsSymlinkOrDirectory`、`TestSaveRejectsFinderAliasTarget` 覆盖缺失但受保护路径、符号链接、目录和真实 Finder alias。
- `TestSaveWriteFailurePreservesDestinationAndCleansTemporaryFile` 注入真实部分写入后 `EIO`，确认旧目标与源字节不变且临时文件清理。
- `TestSaveCancellationBeforeCommitPreservesExistingTarget` 覆盖调用前取消及写完后、commit 前取消；`TestSaveRejectsParentDirectoryReplacementBeforeCommit` 覆盖目录移动后在原路径放入新目录；`TestSaveRevalidatesDestinationProtectionImmediatelyBeforeCommit` 覆盖提交前目标被替换为受保护源硬链接。
- `GOWORK=off go test -race -count=1 ./...`（`apps/goui`）、`make goui-check`、桌面 module `GOWORK=off go vet ./...`、根 module `GOWORK=off go test -count=1 ./...`、`make license` 与 `git diff --check` 均通过。

## 边界与后续

提交前最后一次 context 检查是 rename 的取消边界；rename 开始后取消不能撤销已提交文件。`os.Root` 锚定目录并约束相对路径，但不消除任意外部恶意并发；alias/path 检查与 rename 之间仍依赖本机文件系统的常规稳定性假设。

G30、G32、G33 已把本模块接入查询和报表 Save Panel 流程，并在面板完成后刷新 `ExportProtection`。附件 Open/Finder 动作和目录共享撤销由 G34/G35 管理，不属于本地文件导出写入；其代码与 headless 覆盖已在任务卡记录，macOS 可见界面验收仍未完成。完整 GUI 验收也仍在 G37/G38。
