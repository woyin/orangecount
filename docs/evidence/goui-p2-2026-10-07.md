# MyGo Go UI P2 指令阅读实现证据

日期：2026-10-07。此记录仅证明 G18 的第一版实现和自动化证据，不表示 P2 或 G18 已完成。

## 实现范围

- 新增“全部指令”页面，消费 `internal/desktop` 的 `DirectivesPayload`，提供 all/config 模式、指令类型筛选、文本搜索、排序和 100 条分页。
- config 模式按源码顺序显示；其读取请求不携带日期范围，页面也隐藏日期、币种和估值筛选，避免暗示这些条件会改变配置记录。
- 字段和 metadata 使用类型感知呈现，保留精确金额、小数、NULL、bool、嵌套 list/map、tag `#` 与 link `^` 前缀。
- 交易和生成记录展示posting账户、精确金额、cost/price、来源位置；generated DTO 展示 SourceKind 与 OriginID 关联。
- 附件声明消费 core 返回的 `AttachmentDTO`；UI 展示 basename/status，操作沿用 ID、snapshot、policy 的 Session 重验证路径，不从行文本构造可打开路径。

## 验证

- 公开 `testdata/fixtures/directives/all.bean` 由真实 `desktop.Session` 投影到 UI headless renderer；检查方言生成关联、交易 tags/links、NULL/bool、来源动作和 configuration 源顺序文案。
- 请求单元测试核对 all/config 参数、分页、类型/搜索输入与 64 KiB 上限；formatter 单测覆盖 exact decimal 和嵌套 list/map/amount。
- 当前源码验证通过：`make goui-check`（Go UI 全量测试和 CGO-disabled build）；`GOWORK=off go test -race -count=1 ./internal/app ./internal/workspace ./internal/preferences ./internal/platform ./internal/widgets/queryeditor`；根模块 `GOWORK=off go test -count=1 ./...`；Go UI `GOWORK=off CGO_ENABLED=0 go vet ./...`；`make license` 与 `git diff --check`。gofmt 检查无输出。
- 本记录不记真实GUI、输入法或VoiceOver通过。

## 2026-10-08 原生 GUI 补充

- 新增 `TestNativeDirectiveAndConfigModesRenderCoreRecords`，以公开 `directives/all.bean` 在真实 MyGo 窗口检查 all 模式中的方言生成关联、tag、精确嵌套 decimal、NULL 和 bool。
- 测试将 UI 日期条件设为2099年后从“全部指令”切换到“配置”，核对配置请求未携带日期范围、仍返回记录，并在原生 Accessibility 树中读取源码顺序说明和配置值。
- 该测试使用 `-count=5` 通过；新增后完整24项 `make goui-native-e2e` 通过。未启用 opt-in 时的原生测试跳过检查也通过。

## 2026-10-08 嵌套值与全类验收

- 修复 `formatDirectiveValueDepth` 对核心 `query.PresentedDecimal` 的处理。此前嵌套 list 中的精确 decimal 会把 Go 结构体字段直接显示出来；现在显示 `Exact` 值，并保留 list、NULL、bool 与 quoted string 的类型表现。
- 扩展公开 `directives/all.bean` 的真实 Session + headless UI 测试，核对日期指令、配置记录各自的实际 DTO 类型都能在对应模式呈现。测试覆盖交易、账户开立/关闭、商品、余额断言、补齐、事件、查询、价格、附件、备注、自定义指令，以及 option/include/tag stack/metadata stack 配置；用户插件在公开 fixture 中明确拒绝。
- 新增 `TestNativeDirectiveNestedValuesWrapWithoutLosingTypes`，在900×600真实 MyGo 窗口读取临时账本的嵌套 list；Accessibility 树包含完整长中文、`1.25000000000000000001`、NULL 和 TRUE。长值 frame 为177×153点，位于900×568点内容区内，连续5次通过。
- 定向 core 投影、headless 全类/formatter 测试和 all/config 原生场景通过；随后 `make goui-check` 与完整 `make goui-native-e2e`（36项常规窗口场景）通过。
