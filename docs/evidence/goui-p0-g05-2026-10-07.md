# G05 macOS 面板与外部来源打开首轮记录

日期：2026-10-07。范围：为 Go UI 的原生 Save Panel 增加可取消生命周期，并让账本来源可从当前结果安全地交给外部编辑器。

## 实现

- MyGo fork 增加 `Dialog.SaveWithContext` 和 Darwin cancellable NSSavePanel；取消在 main thread 触发原生 panel 的 cancel action。查询/报表页面已使用它并传入父窗口。
- `platform.OpenSource` 查询 macOS 默认文件处理应用。一般默认应用仍由系统打开；bundle ID 属于 `org.orangecount.*` 或 OrangeCount 名称时改交 TextEdit，TextEdit 不可用则只显示 Finder，避免递归启动 OrangeCount。
- 欢迎页、诊断、指令、交易、账户、商品/报价、持仓和来源行增加“打开源文件”。动作校验 workspace revision、window epoch、operation 与 snapshot，读取或视图切换后的旧按钮不能打开旧来源。

## 验证

- `TestDialogSaveWithContextCancelsVisiblePanel` 覆盖选择、可见面板取消回调与预先取消。
- `TestOrangeCountDefaultHandlerDetection` 覆盖生产/QA/Go UI OrangeCount bundle 与常见外部编辑器分类。
- `TestSourceOpenRequiresCurrentWorkspaceResponse` 覆盖当前 response 可打开及切换操作后的迟到来源动作拒绝。
- Go UI 全量 race、`make goui-check`、Go UI vet、根模块测试、MyGo 定向测试、license 与 diff 检查通过。

## 未完成

G05 仍在进行中：需要在实际 QA/生产 bundle 关联为 `.bean` 默认应用的 macOS 上验证 TextEdit/Finder 路由；两个 Go UI 窗口同时打开文件面板、关闭父窗口后无残留 sheet 也需要 GUI 实机验收。Go UI 没有内置编辑器，来源通过系统外部编辑器打开。
