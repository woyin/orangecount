# Q02 类型化 CSV 与命令行入口

日期：2026-10-01；基线 `9e5d794`，接续已保存 query 目录。

`TypedResult.WriteCSV` 按列序输出，保留重复标题；整数和 Decimal 使用精确字符串，字符串遵循标准 CSV 引号规则，amount/position/inventory 使用包含完整成本的 JSON 单元格。NULL 输出空字段，因此 CSV 不能区分 NULL 与空字符串；无损类型及执行上下文需要独立分析文件。

命令行新增 `query --format typed-csv`，使用与 typed-json 相同的已声明 BeanQuery 子集。旧 json/csv 入口保持原适配语义。该命令重新执行输入查询，不是原生工作台某次成功执行的导出。
