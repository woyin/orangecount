## 实现

- 流水读取请求携带日期区间、窗口、搜索文字、账户、排序、页偏移、每页上限和当前快照身份。核心先筛选整笔交易并计算匹配总数，再只投影当前页；最多读取 100 笔，不触发重新构建账本。
- 页面显示匹配总数、当前范围和快照短标识；提供全文筛选、账户筛选、顺序切换、上一页/下一页。流水页不显示会造成误解的币种/估值控件。
- 交易详情读取核心 DTO 的确切单位、成本日期、`@`/`@@`价格、typed metadata、交易/分录来源；来源动作交给 Finder adapter。交易行使用核心生成的稳定身份，唯一内容可跨无关行位移保留，重复内容身份限定在当前快照。
- Journal DTO 的 metadata 保持在正常 JSON 响应中。当前通用 analysis 导出 schema 不投影动态 metadata，因为其 union 值尚未定义静态导出类型；这项导出表示留给 G32。
