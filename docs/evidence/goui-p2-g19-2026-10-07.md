# G19 诊断页面初版证据

日期：2026-10-07。本记录证明诊断呈现和来源操作的自动化初版，不代表 G19 完成。

## 实现

- 欢迎页继续展示诊断摘要；增加独立诊断导航页，提供 invalid 与 stale 状态说明、severity/code、消息、来源位置和关联来源。
- 主来源和关联来源可复制 `path:line:column`，主来源仍支持 Finder 定位。修复后可使用已有侧栏“重新读取”重新构建当前账本。
- 主来源和关联来源现用 `widgets.SourceRow`，统一显示 path/line/column 与复制、Finder、外部编辑器动作；打开动作捕获当前 epoch/operation/snapshot/revision，并在实际调用时再次校验，避免 stale 诊断打开错账本来源。
- 核心来源正文不加入 UI 状态、诊断按钮或复制文本；复制内容只包含位置。

## 验证

- `GOWORK=off go test ./internal/app -run 'Test(Diagnostic|Diagnostics|Journal|Statement)' -count=1`（`apps/goui`）通过。headless 测试覆盖 invalid 欢迎页来源动作和 stale 诊断页状态、复制位置、Finder 路径。
- `make goui-check` 通过。
- `TestSourceRowActionsAndDisabledOpen` 覆盖来源控件动作与禁用打开；`TestDiagnosticSourceActionRevealsSourceInFinder` 与 `TestDiagnosticsPageDistinguishesStaleAndCopiesCurrentLocation` 覆盖 headless 页面来源位置、复制和 Finder 动作。
- `GOWORK=off go test -race -count=1 ./internal/app ./internal/workspace`（`apps/goui`）通过。
- workspace 的 A/B 连续错误和 invalid 首次打开集成测试见[P1工作区记录](goui-p1-2026-10-07.md)。
