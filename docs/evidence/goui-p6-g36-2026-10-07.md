# G36 菜单与焦点命令首轮记录

日期：2026-10-07。本记录证明原生菜单命令与 Headless 搜索焦点首轮实现，不表示 G36/P6 完成。

## 实现

- 应用菜单提供打开账本（Cmd+O）、新建窗口（Cmd+N）、重读账本（Cmd+R）和查找（Cmd+F）；Edit 菜单通过 MyGo role 保留原生撤销/重做/剪切/拷贝/粘贴/全选路由。
- 主程序按 `*mygo.Window` 维护窗口到 `app.Model` 的映射，菜单命令使用 MyGo 提供的焦点窗口，命令不会落到最近创建的另一个窗口。
- Cmd+F 可在资产负债表/损益表、流水、账户流水、持仓账户搜索、全部指令和查询页聚焦当前搜索框；页面切换会丢弃尚未消费的焦点请求。
- 重新读取菜单和侧栏共用同一工作区命令；没有打开账本时显示明确状态。

## 验证

- `GOWORK=off go test ./internal/app ./cmd/orangecount-goui -count=1`（`apps/goui`）通过。
- `TestApplicationMenuRoutesCommandsAndExposesMacShortcuts` 检查菜单 accelerator、New Window回调、Find当前页焦点请求和无账本Reload状态。
- `TestQueryCatalogueSelectionOnlyFillsTheDraft` 使用真实 Headless 页验证 Cmd+F 请求把焦点放到查询目录搜索框，并在 900×600、TextScale 1.5 环境再次检查页面与搜索控件存在。
- `TestFindFocusesHoldingsAccountSearch` 在 Headless 表单里确认 Cmd+F 后焦点落到“持仓账户”输入框。
- 当前改动后的 `make goui-check`、UI module `GOWORK=off go test -race -count=1 ./...`、`GOWORK=off CGO_ENABLED=0 go vet ./...`、`make license` 和 `git diff --check` 均通过。
