# G32 报表保存首轮实现记录

日期：2026-10-07。范围：把核心提供 `ReportExportIdentity` 的适用页面接入 CSV 与 `.ocanalysis` 保存流程。

## 实现

- 报表工具条仅在当前页面响应含有同一 snapshot 的 `ReportExportIdentity` 时显示；覆盖概览、资产负债表、损益表、流水、账户详情、商品目录/报价历史及持仓 groups/events/history/lots。
- workspace 在捕获前验证 projection ID、snapshot 和 capture scope 仍对应当前保留的报表响应；陈旧 projection 不会进入保存或显示成功。
- CSV 与 `.ocanalysis` 共用 query 保存链路中的原生 Save Panel、扩展名/过滤器、取消与安全文件提交逻辑。面板说明展示投影范围、行数、源记录数、日期、完整性、截断状态和语义 profile。
- 面板返回后刷新同一窗口 epoch 的保护路径；若 reload 新增了源文件，保存会拒绝覆盖该新来源，已冻结报表字节不变。

## 验证

- `TestReportExportControlsCoverSupportedReportPages` 使用公开 fixture 验证 11 类可导出页面/分区均显示保存动作，且响应 identity 与当前页面筛选匹配。
- `TestReportSaveCoordinatorWritesCSVFromCurrentProjection` 验证 CSV 输出、完整投影面板说明及 0600 文件权限。
- `TestReportSaveCoordinatorWritesAnalysisProjection` 用核心 `analysis.ReadReport` 读回分析归档并校验 snapshot、section 和行数据。
- `TestReportSaveCoordinatorCancellationDoesNotWrite` 验证保存面板取消后不产生目标文件。
- `TestReportSaveRefreshesProtectionAfterReloadDuringSavePanel` 验证面板期间 reload 新增来源后拒绝覆盖，并保留面板打开前捕获的报表 bytes。
- `TestReportCaptureRejectsProjectionOutsideCurrentView` 验证 workspace 拒绝缓存中存在但不再对应当前报表响应的旧 projection。
- 2026-10-08 价格历史导出身份补齐选中报价对；中英文面板显示 pair，默认文件名加入 pair 并区分 STK/USD 与 EUR/USD。详见[G23/G32价格报表导出上下文补充](goui-p3-g23-g32-price-export-context-2026-10-08.md)。
- 本轮通过：`make goui-check`、Go UI `go test -race -count=1 ./...`、Go UI `go vet ./...`、根模块 `go test -count=1 ./...`、MyGo 定向测试、`make license` 与 `git diff --check`。
