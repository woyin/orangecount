# G33 查询成功结果保存首轮实现记录

日期：2026-10-07。范围：把已成功执行的查询结果保存到 CSV 或 `.ocanalysis`，并在保存面板期间重新读取工作区保护路径。

## 实现

- 查询页只对当前快照的成功结果开放“保存 CSV…”和“保存分析文件…”；在弹出面板前由 workspace capture API 重新核验 snapshot/request ID/fingerprint/format，并复制固定内容、上下文与来源身份。
- 保存面板显示行数/截断、snapshot 和语义 profile；CSV 保存行投影，`.ocanalysis` 保存上下文、schema 与 typed cells。面板路径无扩展名时补上相应扩展名。
- 接入 `mygo.Dialog.SaveWithContext` 及 Darwin 可取消 NSSavePanel；离页、重开账本、reload、窗口关闭可取消流程。面板返回后刷新同一窗口 epoch 的 `ExportProtection`，将新增来源身份并入 capture，再交给 G31 原子保存。
- workspace controller 增加 epoch/生命周期校验的 protection refresh API；reload 已在途时拒绝保存。

## 验证

- `TestQuerySaveCoordinatorWritesFrozenCSVAfterProtectionRefresh`：固定当前查询内容后保存 CSV，校验字节、面板说明与 0600 权限。
- `TestQuerySaveCoordinatorWritesTypedAnalysisDocument`：写入后通过核心 `ReadQueryAnalysis` 读取，校验查询文本、列和行保留。
- `TestQuerySaveCoordinatorCancellationDoesNotWrite`：取消面板上下文后不创建目标文件。
- `TestQuerySaveCoordinatorRejectsResultAfterQueryChanges`：成功查询之后执行失败的新查询，旧成功结果不能启动保存。
- `TestQuerySaveCoordinatorCancelsWhenLeavingQueryPage`：离开查询页会取消可见保存面板。
- `TestQuerySaveRefreshesProtectionAfterReloadDuringSavePanel`：面板期间加入并重载新的来源文件，保护刷新拒绝将该源覆盖，且捕获字节保持原值。
- MyGo 测试 `TestDialogSaveWithContextCancelsVisiblePanel` 覆盖成功选择、可见面板取消回调和预先取消。
- 本轮通过：`make goui-check`、`GOWORK=off go test -race -count=1 ./...`（apps/goui）、`GOWORK=off go vet ./...`（apps/goui）、MyGo 定向包测试、根模块 `GOWORK=off go test -count=1 ./...`、`make license` 与 `git diff --check`。
