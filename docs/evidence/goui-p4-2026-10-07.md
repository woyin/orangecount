## 已实现并由自动化观察

- `apps/goui/internal/app/query.go` 提供带可访问标签的原生 BQL TextArea、显式执行/取消按钮和 Cmd+Enter。编辑草稿不自动执行；Cmd+Enter 走同一个 UTF-8 64 KiB 限制。Headless composition 测试验证标记中的输入法文本不会被快捷键提交；真实系统输入法仍未测试。
- 错误响应显示类型化错误和 UTF-8 byte range。`queryeditor.SelectByteRange` 转换为 rune 选区并调用 MyGo fork 的公开 `ui.Element.SetTextSelection`。真实 DesktopEngine fixture 的查询 `SELECT '💰', missing LIMIT 0` 返回 `missing` token 的精确 byte range；原生查询页定位后输入 `account`，只替换该 token，emoji 保持正确。
- 查询结果保留独立的执行文本、snapshot ID、semantics profile、evaluation revision 和 fingerprint；展示返回/上限行数、UTF-8 文本字节和工作预算步数。修改 draft 保留旧执行与结果，提供恢复执行文本按钮。工作区继续通过独立 query runner 处理 supersede、取消和账本生命周期。
- 结果第一版使用 MyGo 虚拟 `ui.Table` 和 core typed positional cells。fixture 的重复列标题仍得到两个不同列 ID 并分别显示。NULL、复合值专用视图、选择/复制和动态列持久化仍属 G27 未完成项。
- 新增 opt-in macOS 原生窗口测试，使用 AppKit `Edit > Undo` 与 `Edit > Redo` 菜单角色撤销/重做实际 BQL TextArea 字符替换；草稿和原生 input client 文本均恢复到精确值，且未隐式运行查询。`./apps/goui/native-e2e.sh -run '^TestNativeQueryEditorUndoRedoUsesEditMenuRoles$' -count=5` 连续5次通过。
- 新增原生 `Edit > Select All / Copy / Paste` 测试，使用含中文和 emoji 的 BQL 草稿检查完整复制、选中替换与“不自动执行”。原生菜单命令异步进入 MyGo 下一帧，因此测试等待输入客户端和剪贴板更新后再断言；完整快照并恢复 general pasteboard 的全部项目、格式顺序和字节，若遇到不能安全保存的 promised type 则跳过，不改动原内容。`./apps/goui/native-e2e.sh -run '^TestNativeQueryEditorCopyAndPasteUsesEditMenuRoles$' -count=5 -v` 连续5次通过。
- G26 查询运行中取消现在有单独的“正在取消…”状态，重复取消按钮会禁用。headless 状态测试通过；原生 E2E 将真实 Desktop Session 查询挂起，在窗口内按“取消查询”，确认被取消的 request ID 正是当前 generation，随后收到 typed `cancelled` 响应。`./apps/goui/native-e2e.sh -run '^TestNativeQueryCancelButtonCancelsCurrentExecution$' -count=5 -v` 连续5次通过。
