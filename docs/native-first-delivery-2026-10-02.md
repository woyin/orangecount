# 原生开发版使用说明（2026-10-02）

本机 arm64 开发版，采用 ad hoc 签名；没有 Developer ID 签名或公证。目标系统声明与限制见 native-macos-support.md；旧系统实机验收未完成。

## 开始使用

解压开发包后打开 OrangeCount.app，通过“打开…”选择账本入口 main.bean。也可将账本文件交给应用打开。用户账本保持只读；加载失败时查看诊断。已有有效快照时，错误重载会保留旧数据并显示错误，不能将旧数据误认为最新输入。

默认会计语义为 legacy。需要本项目修订的 booking、容差及 AVERAGE 行为时，在页面“会计语义”中选择 v3，检查迁移比较后应用；不会修改账本源文件。查询能力以 query-capability-matrix.md 为准。

可使用报表、趋势、账户、流水、持仓、价格与查询工作台。查询预设先填入草稿，需要显式执行；CSV 与分析文件导出针对已捕获的成功执行。不要通过导出覆盖账本或附件。

日记账可选择交易、全部指令和配置。配置指令不适用日期过滤；全部指令保持有效日期过滤。生成交易显示来源关联。附件声明可以在全指令中阅读，但原生附件列表和附件打开流程尚未交付。
