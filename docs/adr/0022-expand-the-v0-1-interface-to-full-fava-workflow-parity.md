# Expand the interface to full Fava workflow parity

The original read-only first-release boundary is superseded: OrangeCount will implement Fava's complete local interface workflows, including usable editor and import surfaces, while retaining a Go-native implementation and local source-ledger authority. The compatibility target is user-visible Fava page and interaction parity, not Fava's Python internals, plugin execution, or public HTTP API.
