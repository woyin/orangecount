# Release original code under Apache-2.0

OrangeCount will be open source under Apache-2.0. Since Beancount is GPLv2-only and Apache-2.0 is not GPLv2-compatible, OrangeCount must remain a clean-room implementation: it may use public language behavior and isolated command-line differential tests, but must not copy, link, bundle, or distribute Beancount GPL code; releases require dependency license scanning.
