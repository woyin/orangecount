# Separate UX parity from accounting semantic authority

Fava is the authority for OrangeCount's observable UX parity, while Beancount v3 remains the authority for ledger evaluation, valuation, and BeanQuery result semantics. Where those sources disagree, OrangeCount retains the deterministic v3 result and applies the Fava-aligned presentation; this preserves the established compatibility contract without weakening the intended local Fava experience.
