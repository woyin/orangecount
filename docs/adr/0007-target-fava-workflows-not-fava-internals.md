# Target Fava workflows, not Fava internals

The Go-native interface will reproduce Fava's essential read-only personal-ledger workflows—exploration, filtering, reports, holdings, queries, document links, diagnostics, and source navigation—without compatibility promises for Fava's UI, HTTP API, editor, or plugin ecosystem. This directs effort toward durable user value rather than coupling OrangeCount to Python implementation details that are out of scope.
