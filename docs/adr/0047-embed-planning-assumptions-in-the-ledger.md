# Embed planning assumptions in the ledger

OrangeCount will store owner-confirmed planned cash flows, reserves, and related planning configuration as versioned standard Beancount `custom` directives, optionally grouped in a dedicated included `planning.bean` file. Plans have stable identities and changes append superseding revisions rather than overwriting or deleting prior assumptions. This keeps planning assumptions local, reviewable, portable, auditable, and backed up with the source ledger while ensuring they are not represented as future transactions and never change accounting balances; private application preferences, mutable records, and a sidecar database were rejected because they separate or erase a financial decision's assumptions from the owner-controlled ledger.
