# Use single-session-model execution with preserved role separation

OrangeCount will execute frontend-transplant work with whatever single session model the coordinating agent runs, dropping the earlier requirement for two distinct Herdr agents bound to specific external models. The product owner retired the dual-model division of labor on 2026-08-05 because model availability, not capability separation, had become the binding constraint. The underlying control survives as role separation rather than model identity: whoever implements a change may not self-certify Gate 3 visual fidelity, and every visual baseline update or Approved Fava deviation still requires explicit product-owner approval. This is reversible: reinstating separate implementer/certifier models is a tooling change, not a semantic one.
