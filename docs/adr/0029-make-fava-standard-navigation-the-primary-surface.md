# Make Fava standard navigation the primary surface

OrangeCount will make the Fava 1.30.12 main navigation, default page, URL routes, and page hierarchy its primary interface surface. OrangeCount-only capabilities may remain as clearly labeled extensions only when Fava has no corresponding capability, and they must not displace or visually compete with the Fava standard navigation; this resolves the conflict between complete UX parity and useful product-specific tooling.
