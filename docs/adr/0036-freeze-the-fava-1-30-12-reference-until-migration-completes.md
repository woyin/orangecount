# Freeze the Fava 1.30.12 reference until migration completes

The Fava 1.30.12 release and its exact source commit are the fixed parity reference for this migration; no upstream UI changes are incorporated until all in-scope routes pass the UX parity gate. A later Fava upgrade is a separate project requiring a new source inventory, dependency and license audit, and visual-baseline review, preventing the implementation target from drifting mid-migration.
