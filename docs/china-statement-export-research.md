# 中国常用账户账单与流水文件获取研究

> 调研对象：招商银行信用卡、广发银行信用卡、招商银行借记卡、工商银行借记卡、微信支付、支付宝  
> 研究截止日：2026-08-12  
> 目的：确认个人用户可以从各机构取得什么文件，以及这些文件能否成为 OrangeCount 的本地导入输入。本文只陈述可核验事实，不作产品优先级或架构决策。

## 研究口径与证据限制

- 只把机构官网、官方帮助中心、官方协议/隐私政策、官方开放平台和官方 App 内帮助视为一手证据。
- “可在 App 中查看”不等于“可以导出机器可读文件”；“商户账单 API”也不等于个人消费者可以授权第三方读取自己的流水。
- 银行与支付 App 的菜单会随版本、灰度和地区变化。若官方公开网页仅证明功能存在、未公开完整入口或格式，本文不会用第三方教程补成确定事实。
- 微信支付和支付宝的个人账单下载说明主要位于登录后的 App 内，未找到稳定、无需登录且可直接引用的官方公开帮助页。因此，下文把常见的 App 路径列为“待真机复核”，不把其时间上限、压缩密码、列名等写成已经由公开一手资料证实的事实。
- “未发现个人 API”表示在本次检索覆盖的官方开放平台中没有找到相应公开产品；它不是对机构所有非公开合作能力的绝对否定。

## 快速结论

| 渠道 | 官方已证实的文件/交付能力 | 机器可读性 | 证据完整度 | 个人本地账本直接授权 API |
| --- | --- | --- | --- | --- |
| 招商银行信用卡 | 自助渠道查账；可选择电邮对账服务 | 未由公开官方资料确认附件格式 | 中 | 未发现 |
| 广发银行信用卡 | App/网银查账；每月电邮对账单；可申请近 12 期账单 | 未由公开官方资料确认附件格式 | 中 | 未发现 |
| 招商银行借记卡 | App“交易流水打印”，邮件交付，另有申请记录与解压码 | 文件格式未由页面文本明确；字段适合结构化解析 | 高（格式除外） | 未发现 |
| 工商银行借记卡 | 个人网银历史明细可下载文本或 Excel；手机银行可查 5 年 | 高 | 高（但公开下载指引较旧） | 未发现 |
| 微信支付 | 个人 App 内有账单下载流程；公开网页仅能充分证明商户账单 API | 个人文件格式待真机复核 | 低（公开证据不足） | 未发现；商户 API 不适用 |
| 支付宝 | 电脑端可下载可编辑的余额收支明细；App/电脑可开具流水证明；另有商户 XLS/CSV 与商户账单 API | 余额明细可编辑，但扩展名未公开；证明文件格式待样本复核 | 中 | 未发现；商户 API 不适用 |

## 1. 招商银行信用卡

### 已由官方资料确认

- 招商银行把手机银行、掌上生活、手机官网、网上银行、短信、官方微信和电子邮箱列为信用卡电子对账服务渠道；短信或微信通知会引导用户进入手机官网、掌上生活或网银查看账单明细，用户也可以选择通过电子邮箱接收对账服务。[招商银行信用卡业务协议中的对账服务说明](https://s3gw.cmbchina.com/lb50.01-cmbweb-prd/cmbcms/20221110/4131caba-0013-4ec2-b28e-cbe526d29754.pdf)
- 官方用卡材料给出的自助查询方式是：手机端使用“招商银行信用卡”公众号或“掌上生活”；电脑端登录网上银行大众版或专业版后进入“账户管理”。[招商银行《金融万里行》账单查询说明](https://market.cmbchina.com/personal/jrzswlx/k/k1/6.html)
- 官方资料确认账单明细可被查询，且电邮对账服务存在；但公开资料没有确认电邮内容究竟是 HTML 正文、PDF、CSV/XLS 附件还是其他格式，也没有公开附件是否加密、历史月份上限或字段表。

### 实际获取入口

1. **查询**：掌上生活或招商银行 App 内进入信用卡账单；网页公开资料只给出渠道，没有给出截至 2026-08-12 仍稳定的完整点击路径。
2. **周期性获取**：在信用卡资料/对账服务中登记有效电子邮箱，接收月度电子对账服务。官方协议只确认可以选择电子邮箱，没有公开附件规格。
3. **人工补取**：公开协议提到可申请纸质账单，但这不构成适合本地账本导入的机器可读文件。[招商银行信用卡业务协议](https://s3gw.cmbchina.com/lb50.01-cmbweb-prd/cmbcms/20221110/4131caba-0013-4ec2-b28e-cbe526d29754.pdf)

### 时间范围、交付、格式与限制

| 项目 | 结论 |
| --- | --- |
| 时间范围 | 月度账单成立；公开官方材料未确认 App 可导出的历史期数 |
| 交付方式 | App/网银页面查看；电子邮箱对账服务；可申请纸质账单 |
| 文件格式 | **未由公开官方资料确认** |
| 密码/加密 | **未由公开官方资料确认** |
| 字段 | 官方只确认“账单明细”，没有公开个人电邮账单字段表 |
| 已知限制 | 没有有效邮箱就无法通过电子邮箱接收；“可查看”不能据此推定存在 CSV/XLS 导出 |

### 官方 API

未发现面向普通个人、允许本地账本通过 OAuth 一类授权读取持卡人全部信用卡交易的公开 API。招商银行的掌上生活开放平台要求合作方提交接入申请、取得 `mid`/`aid`、交换密钥并由平台开通接口权限；公开门户描述的开放能力集中于用户体系、支付、营销和运营数据，未公开个人持卡人账单读取产品。[掌上生活开放平台接入指南](https://open.cmbchina.com/Platform/src/documents/overview/guide.html) [掌上生活开放平台门户](https://open.cmbchina.com/Portal/)

## 2. 广发银行信用卡

### 已由官方资料确认

- “发现精彩”App：搜索并进入“查账还款”，点击“查账”；广发银行手机银行：搜索“账单查询”后点击“查账”；官方微信也可查询交易明细。[广发信用卡《账单明细查询》](https://card.cgbchina.com.cn/Info/23445901)
- 个人网银的传统路径是“信用卡 → 账户管理 → 账单查询”，可以查询当期及历史账单。[广发信用卡账单服务调整通知](https://card.cgbchina.com.cn/Info/19695863)
- 银行每月可向预留电子邮箱发送对账单；官方列出的发件地址包括 `creditcard@cgbchina.com.cn` 和 `creditcardbill@cgbchina.com.cn`。[2026-05-29 信用卡账务与账单帮助](https://xyk.cgbchina.com.cn/Info/23446165)
- 最新个人卡客户协议确认：月度对账单包含上一账单周期已入账交易明细、应还总额、最低还款额和最后还款日；没有交易且没有未偿余额时可以不提供账单；除月度账单外，客户可每年免费另行要求一次近 12 期账单。[广发银行信用卡客户协议（个人卡）](https://card.cgbchina.com.cn/jsp/pdf/Rate_27275104_v4.0.pdf)

### 时间范围、交付、格式与限制

| 项目 | 结论 |
| --- | --- |
| 时间范围 | 当期及历史账单；协议明确可每年免费另行要求一次近 12 期账单 |
| 交付方式 | 发现精彩 App、手机银行、官方微信、个人网银查看；预留邮箱每月接收对账单；客服/其他渠道申请重出 |
| 文件格式 | **公开官方资料未确认电邮附件格式，也未承诺 CSV/XLS 导出** |
| 密码/加密 | **未由公开官方资料确认** |
| 字段 | 协议明确至少包括周期内已入账交易明细、应还总额、最低还款额、最后还款日；争议条款举例交易时间、金额、商户名称 |
| 已知限制 | 无交易且无未偿余额的周期可能不生成账单；邮箱投递依赖预留地址有效；查询页面不等于可取得可解析文件 |

### 官方 API

未发现面向普通个人账本的信用卡交易授权读取 API。广发公开的系统对接/财资能力以企业金融和定制服务为主，不能当作个人卡授权接口。[广发银行服务收费价目表中的财资通/业财互联](https://www.cgbchina.com.cn/jsp/pdf/Rate_27568864_v3.0.pdf)

## 3. 招商银行借记卡

### 实际入口与已证实流程

招商银行提供了公开的官方图文指引：登录招商银行 App 后，依次进入“全部 → 便民 → 流水打印”。在申请页选择卡号、时间跨度、起止日期、交易币种和展示项，填写接收邮箱，阅读并同意协议后提交，再输入该卡取款密码。[招商银行 App“交易流水打印”操作指引](https://market.cmbchina.com/MPage/online/220624162830519/suus.html)

官方指引还显示：

- 时间跨度至少包含“一年内”，官方示例的起止日期正好跨一年；页面也提供更短跨度选项。
- 可以选择是否展示交易对手信息、完整卡号、收入及支出汇总金额，并可按交易币种、金额区间、收支类型过滤。
- 交付方式为用户填写的电子邮箱。
- 申请提交后可以进入“申请记录”查看状态；文件到达后可在申请记录中查看“解压码”。这足以确认交付文件经过压缩加密，但公开页面的可检索文本没有给出加密算法或压缩格式。
- 官方指引和隐私政策列明流水可能包含交易日期、交易币种、交易金额、账户余额、交易摘要和交易对手信息，并涉及卡号、账户类型/等级和开户行。[招商银行 App 隐私政策（流水打印条款）](https://market.cmbchina.com/MPage/online/230201140145350/privacy.htm)

### 时间范围、交付、格式与限制

| 项目 | 结论 |
| --- | --- |
| 时间范围 | 官方图文明确展示可申请一年跨度；没有公开证明单次可超过一年 |
| 交付方式 | 发送至申请时填写的电子邮箱 |
| 文件格式 | 官方页面标题和流程确认“流水打印”文件，但未在可公开引用文字中明确 PDF/CSV/XLS/XLSX；需要用真实文件定版 |
| 密码/加密 | 有“解压码”，可在 App 的申请记录中查看 |
| 字段/筛选 | 日期、币种、金额、余额、摘要、交易对手；可选择是否展示对手信息、完整卡号、收支汇总，并按币种/金额/收支筛选 |
| 已知限制 | 需要登录并验证取款密码；邮件是异步交付；文件格式和实际编码必须以样本确认 |

招商银行另有公开的交易流水验真页面，验真输入项包括打印/申请日期、记账日期、币种、收入或支出金额及余额，并称只支持验证申请时间半年内的流水。这能验证字段及“正式流水文件”的存在，但“半年”是**验真窗口**，不是流水可申请时间范围。[招商银行交易流水验真](https://checktransactionbill.paas.cmbchina.com/checkTransaction)

### 官方 API

未发现面向普通个人本地账本、由用户授权持续读取一卡通交易的公开 API。公开的招行开放平台资料要么属于掌上生活合作方接入，要么属于企业/机构能力，不能据此推定个人账户数据可拉取。[掌上生活开放平台接入指南](https://open.cmbchina.com/Platform/src/documents/overview/guide.html)

## 4. 工商银行借记卡

### 手机银行查询

官方帮助给出的当前查询入口是“中国工商银行”手机银行的“最爱 → 我的账户 → 查询明细”，可查看 5 年内的账户资金收支，点击单笔可查看更详细信息。部分独立分行可能执行不同规定。[工行《如何使用手机银行查询明细？》](https://wap.icbc.com.cn/icbc/grdzyx3/511.htm)

该页面只确认**查询**，没有确认手机 App 可以把 5 年数据导出文件。

### 个人网银文件下载

工行公开的个人网银帮助明确说明：

- “账户历史明细查询”可按注册卡、下挂账户、币种、开始日期和截止日期查询一年内的交易详细记录。
- 查询结果可选择“文本格式”或“EXCEL 格式”下载。
- 页面每次最多显示 150 笔，因此高频账户需要缩小时间段或经常查询；公开材料没有明确文件下载是否也被 150 笔截断，不能假定下载文件一定不截断。[工行《账户历史明细查询》](https://www.icbc.com.cn/icbc/html/help/jraj/wdzh/wdzh_002_5.htm)
- 当日明细同样可下载文本或 Excel。[工行《账户当日明细查询》](https://www.icbc.com.cn/icbc/html/help/jraj/wdzh/wdzh_002_4.htm)

### 时间范围、交付、格式与限制

| 项目 | 结论 |
| --- | --- |
| 时间范围 | 手机银行查询 5 年；个人网银公开下载指引为一年内 |
| 交付方式 | 个人网银直接下载到本机；手机银行用于页面查询 |
| 文件格式 | 文本、Excel（官方原文使用“EXCEL”，未区分 `.xls` 与 `.xlsx`） |
| 密码/加密 | 公开个人网银帮助未说明下载文件加密或密码 |
| 字段/条件 | 注册卡、下挂账户、币种、开始/截止日期；内容覆盖柜面、购物消费等交易详细记录，官方未公开完整列名表 |
| 已知限制 | 公开网银帮助页较旧，需用当前网银样本确认格式与编码；独立分行规则可能不同；页面最多展示 150 笔 |

### 官方 API

工行有官方 API 开放平台，但检索到的公开接入材料主要是企业/银企互联场景，例如企业 ERP 通过专线和证书接入。未发现普通个人通过 OAuth 一类授权把借记卡全量流水交给本地账本的公开产品。[工行 API 开放平台](https://gw.open.icbc.com.cn/ui/) [工行银企互联企业开发手册](https://open.icbc.com.cn/icbc/apip/mdres/bank_enterprise_access.pdf)

## 5. 微信支付

### 个人账单文件：公开证据不足

微信 App 的登录后界面提供个人账单及下载能力，但本次没有找到腾讯/微信支付在开放网页上发布的、无需登录即可稳定引用的个人下载说明。常见入口通常位于“我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单”，并区分个人对账与证明用途；**该路径、单次时间上限、CSV 列名、邮件压缩包和解压密码的具体行为必须在目标版本真机复核后才能进入正式兼容规格**。

因此，本研究不把网上常见的“三个月上限”“CSV 邮件压缩包”“特定密码通知方式”当作已由公开一手资料证实的事实。

### 可由官方公开资料确认的边界

微信支付公开的“申请交易账单”API 是**商户 API**：微信支付在次日生成商户交易账单，商户凭商户号、商户 API 证书等凭据申请下载链接；它不是消费者授权读取个人微信支付历史的接口。[微信支付商户文档：申请交易账单](https://pay.wechatpay.cn/doc/v3/merchant/4013070395) [微信支付商户文档：下载账单](https://pay.wechatpay.cn/doc/v3/merchant/4013071227)

### 时间范围、交付、格式与限制

| 项目 | 个人用户结论 |
| --- | --- |
| 实际入口 | App 内入口存在，完整菜单需真机复核；没有找到稳定公开帮助 URL |
| 时间范围 | 未由可公开访问的一手资料确认 |
| 交付方式 | 未由可公开访问的一手资料确认 |
| 文件格式 | 未由可公开访问的一手资料确认 |
| 密码/加密 | 未由可公开访问的一手资料确认 |
| 字段/限制 | 未由可公开访问的一手资料确认；须以真实个人导出样本建立字段表 |
| 个人 API | 未发现；商户账单 API 不能用于读取用户在所有商户处的个人消费流水 |

## 6. 支付宝

支付宝需要区分三种不同的数据产品；它们的覆盖范围不能互相替代。

### A. 余额收支明细：可编辑文件

支付宝官方服务中心给出的电脑端路径是：登录支付宝账户，在“账户余额”板块点击“查看”，选择时间范围后点击“下载查询结果”。可按资金流向、类型、金额区间和关键词筛选，官方明确说下载的收支明细“可编辑”，但没有公开扩展名，因此不能仅凭“可编辑”写成 CSV/XLS。[支付宝《如何下载支付宝余额收支明细》](https://cschannel.alipay.com/mobile/helpDetail.htm?help_id=201603346502)

手机端“我的 → 余额 → 全部”，或余额页右上角“... → 余额变动明细”，可查询近一年；更多历史需使用电脑端。手机端不能直接下载收支明细，但可申请证明。[支付宝《如何查询支付宝余额变动明细》](https://cschannel.alipay.com/mobile/helpDetail.htm?help_id=201602058496)

这里的对象是**支付宝余额的变动**，不能未经样本验证就当作所有银行卡、花呗等支付方式形成的完整支付宝支付账单。

### B. 账单交易流水证明

官方入口是“支付宝 App → 我的 → 账单 → 右上角三个点 → 开具交易流水证明”；也可从某笔交易进入“查看往来记录”，再从右上角开具指定交易对象的流水证明。[支付宝《如何开具支付宝交易流水证明》](https://cschannel.alipay.com/mobile/helpDetail.htm?help_id=201602688026)

官方公开页面没有写明证明文件的扩展名、密码/加密方式、完整字段或单次时间上限，这些仍需以真实导出样本确认。

### C. 余额收支明细证明

手机端路径是“我的 → 总资产 → 资产证明 → 余额资产和流水证明 → 流水证明”，选择时间段，输入接收邮箱，并验证身份证号和支付密码后开具。电脑端也可从“服务大厅 → 自助服务 → 电子凭证 → 收支明细证明”筛选并下载。官方明确单次最多 1000 条；超过时需缩短范围，或改开账单交易流水证明。[支付宝《如何开具支付宝余额收支明细证明》](https://cschannel.alipay.com/mobile/helpDetail.htm?help_id=201602096970)

支付宝 App 的逐笔账单详情还会显示交易涉及的商户和金融机构，官方说明确认交易信息包括交易编号、金额、对象和时间。[支付宝向第三方共享个人信息的情况说明](https://render.alipay.com/p/c/18qd2eli72kg)

### 商户能力不能替代个人能力

- 支付宝商家中心“交易订单”允许商户对查询结果选择 XLS 或 CSV 下载，下载结果是 ZIP；字段可包括创建时间、商品名称、支付宝交易号、交易对方、订单金额、退款金额和交易状态等。这是商户自己的买入/卖出订单数据，不是消费者全账户流水授权。[支付宝商家中心《交易订单》](https://help.alipay.com/enterprise/knowledgeDetail.htm?knowledgeId=201603401913)
- 商户可从“对账中心 → 账单下载”下载账单，也可调用 `alipay.data.dataservice.bill.downloadurl.query` 获取账单文件；账单类型和生成周期均围绕商户交易、资金、费用和营销账单。[支付宝商家账单获取说明](https://help.alipay.com/enterprise/knowledgeDetail.htm?knowledgeId=201603401890) [支付宝开放平台账单下载接口](https://opendocs.alipay.com/apis/api_15/alipay.data.dataservice.bill.downloadurl.query)

### 时间范围、交付、格式与限制

| 项目 | 个人用户结论 |
| --- | --- |
| 实际入口 | 余额明细由电脑端账户余额板块下载；交易流水证明在 App 账单页右上角；余额证明在总资产的资产证明中 |
| 时间范围 | 手机余额明细查询近一年，更多历史用电脑；余额证明单次最多 1000 条；其他时间上限未公开 |
| 交付方式 | 余额明细电脑直接下载；余额证明可发送至填写的邮箱；交易流水证明的交付细节未在公开文字中完整说明 |
| 文件格式 | 余额收支明细官方称“可编辑”，但未给扩展名；证明文件格式未公开；商户端 XLS/CSV 不能外推 |
| 密码/加密 | 余额证明申请需身份证号和支付密码验证；下载文件是否另有密码未公开 |
| 字段 | 可按资金流向、类型、金额和关键词筛选；逐笔详情含交易编号、金额、交易对象、时间及商户/金融机构信息；导出列名待样本确认 |
| 个人 API | 未发现；公开账单 API 面向商户，不是个人消费者 OAuth 流水聚合接口 |

## “文件获取层而非机构直连”的事实性可行性矩阵

下表只评价**能否从用户自行取得的文件开始做兼容**，不评价是否应该做、先做哪家或如何设计产品。

| 渠道 | 用户能自行取得某种账单/流水 | 官方确认机器可读格式 | 可自动化获取的稳定性 | 首个解析器所需的最小补证 | 文件获取层的事实性可行性 |
| --- | --- | --- | --- | --- | --- |
| 招商银行信用卡 | 是：查询与电邮对账 | 否 | 月度电邮可能稳定，但附件规格未知 | 一封真实电邮账单及其附件/正文；至少两个账期 | 条件可行：先取得样本，不能先假定 CSV |
| 广发银行信用卡 | 是：查询、月度电邮、近 12 期补取 | 否 | 月度电邮渠道官方明确 | 一封真实账单；确认文件类型、编码、是否加密及无交易月份行为 | 条件可行：来源稳定，格式待证 |
| 招商银行借记卡 | 是：App 申请并邮件交付 | 未明确 | 官方流程清晰，异步邮件交付 | 一份真实文件；确认扩展名、压缩格式、编码、表头与解压流程 | 较高：申请/交付/解压均有官方依据 |
| 工商银行借记卡 | 是：个人网银直接下载 | 是：文本、Excel | 手工网银下载；当前格式需复核 | 当前网银下载样本；验证 150 笔边界、扩展名和编码 | 高：公开官方资料明确存在机器可读下载 |
| 微信支付 | 是：App 内个人账单下载（需真机确认规格） | 公开网页未确认 | 取决于 App 内手工申请和邮件行为 | 当前 App 全流程录屏/截图；真实导出包；不同时间段和退款样本 | 条件可行，但公开证据缺口最大之一 |
| 支付宝 | 是：电脑余额明细下载；App/电脑开具证明 | 余额明细可编辑，扩展名未公开 | 余额明细电脑下载路径明确；证明需身份验证 | 余额明细与交易流水证明各一份；确认二者覆盖范围、扩展名、编码和列名 | 较高，但必须区分余额流水、交易流水证明与商户账单 |

## 样本验收清单

若后续由账户持有人亲自导出样本，至少记录以下事实，才能把本研究转化为可重复的兼容规格：

1. App/网银版本、操作日期、完整菜单路径和可选时间范围。
2. 文件名、扩展名、MIME、压缩格式、是否加密、密码从何处取得。
3. 文本编码、分隔符、换行符、小数点、货币单位、时区和日期语义（交易日/记账日/入账日）。
4. 原始表头、说明行、合计行、账户掩码、交易唯一标识、商户/对手、支付渠道、状态、退款/撤销/手续费表示方式。
5. 空账期、跨币种、信用卡还款、退款、红包/转账、余额变化、超过页面笔数上限时是否完整。
6. 同一渠道至少保留两个不同账期或不同版本的样本，用于判断模板是否稳定；样本需脱敏，但脱敏不能破坏分隔符、列数和类型特征。

## 结论边界

官方证据已经足以证明：六个渠道都存在用户可查看或取得账务记录的官方路径，但只有工商银行借记卡的公开材料明确承诺个人网银可下载文本/Excel；招商银行借记卡明确存在异步邮件流水文件和解压码；支付宝明确可在电脑端下载可编辑的余额收支明细，并可开具两类流水证明；两家信用卡主要能确认月度电邮对账；微信个人文件以及其他渠道未公开的扩展名、编码和字段仍须靠账户持有人完成一次受控导出才能定版。六家均未在本次官方公开资料检索中提供“普通个人授权本地账本持续拉取全量交易”的通用 API；公开支付 API 和银行系统对接能力分别面向商户或企业合作场景。
